# Mininova wavetables

Novation Mininova has 36 built-in wavetables. Problem is that Novation did not bothered to document what sounds are inside those, they just named it from `Wawetable1` to `Wavetable36`. To make things even worse is seems like those wavetables are not in some logical order (e.g. from sine wave to harmonically more rich content as seen in other synths) but in seemingly random order.

To quote Novation itself from [this review of Ultranova](https://www.matrixsynth.com/2016/09/matrixsynth-review-and-overview-of.html) (which uses same engine):

> “The wavetables were generated in house, it was a largely experimental process to define the wavetables. Some were attempts at using additive synthesis to copy some wave types – like the reed instruments and some of the organ instruments. Others like some of the bell and harsh timbres were the result of experimentation. The first 16 wavetables (0-16) were a deliberate attempt to keep like waves together. The next  (17-32) were designed to group unlike wave together. As the project progressed, it became apparent that naming the wavetables and trying to give each wavetable a particular meaning was not that useful. The best approach to using them is by using them.”

This project aims to document those to help making Mininova presets easier.
